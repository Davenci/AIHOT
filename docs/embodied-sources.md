## 采集范围

- arXiv 使用 cs.RO RSS；标题与摘要匹配 VLA、世界模型、人形机器人、具身、机器人学习、模仿学习、强化学习、导航、机器人数据或自动驾驶等词才进入处理。
- Hugging Face 使用 Daily Papers JSON 接口，映射论文标题、摘要、原始发表时间和第一作者，链接到 arXiv 原文，以复用现有 URL 去重。关键词限制比 arXiv 更窄，不用泛化的强化学习一词放行所有 LLM 论文。
- 两个论文平台是发现入口，不代表作者所属机构；按 T2 处理，不设置平台为论文主体。
- NVIDIA 使用 Robotics 分类技术博客；IEEE 使用 Robotics 专题 RSS。
- Waymo 只读研究列表顶部 8 个论文卡片中的 arXiv 原文链接，每轮最多读取 4 个详情页；从论文 citation_date 元数据读取真实发表日期，按 UTC 解释。列表本身没有可靠的完整日期，不从年份或抓取时间编造时间。日期验证确认其中存在历史论文，后续窗口不会把旧研究当新新闻补入。首轮已有的 4 条无日期归档保留，不强行放进动态列表。
- 所有新源关闭站内全文和全文 RSS，仅发布摘要和原文链接。

`ingestNoiseFilter` 使用现有实现的关键词保留规则：`dropMarkers` 的空字符串匹配全部条目，`keepIfMatches` 命中相关关键词后优先保留，形成明确的关键词白名单。保存配置前已通过正式 `previewSource` 验证实际结果，没有新增框架代码。

## 导入与后续更新

首次采集合计最多 22 条，已实际导入 22 条。首次数量上限仅控制初始化，不是永久的每日条数上限；之后按当前采集间隔读取新条目，仍受关键词过滤、URL 去重、框架时间窗口、模型预算和筛选规则约束。上述间隔是试运行初始配置；框架每天北京时间 04:20 按产出自动调整，普通 editorial 订阅源会调整到 15–60 分钟，调整不会立即改写已经排定的下一次抓取时间。Waymo 的列表读取范围持续限制在顶部 8 项。

论文不会因为被采到就自动成为精选。未达到精选门槛但满足浏览条件的内容，可在 `/all?category=paper` 查看。旧内容没有批量重筛或删除。
