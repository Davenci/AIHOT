【具身智能与自动驾驶领域规则】

- VLA = 视觉语言动作模型；world model = 世界模型；embodied data = 具身数据；robot learning = 机器人学习。
- policy 在机器人语境译作策略；behavior cloning = 行为克隆；imitation learning = 模仿学习；reinforcement learning = 强化学习；sim-to-real 保留英文或译作仿真到现实。
- navigation = 导航；localization = 定位；mapping = 建图；planning = 规划；control = 控制；perception = 感知；manipulation = 操作。
- autonomous driving / self-driving = 自动驾驶；ADAS 保留英文；end-to-end driving = 端到端自动驾驶；occupancy = 占用预测；trajectory = 轨迹。
- humanoid robot = 人形机器人；mobile manipulator = 移动操作机器人；grasping = 抓取；dexterous hand = 灵巧手；teleoperation = 远程操作。
- robotics、VLA、世界模型、数据集、模型、公司、实验室和基准名称保留官方英文或中文品牌名，不自造译名。
- 论文、代码、数据集、模型权重、GitHub 地址、URL、命令、数字、单位、版本号和实验条件原样保留。不要把论文中的未来计划写成已完成结果。
- 公司的宣传性能力描述必须写成“公司称”或“公司公布”，不能改写成已经验证的行业事实。
